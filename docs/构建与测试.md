# 从源码运行和打包

## 准备环境

开发环境使用 Windows x64、Python 3.13 和 Microsoft Edge WebView2。要转换音频或预览奥3的 IPU 影片，还需要把 FFmpeg 加入 `PATH`。运行前端测试需要 Node.js。

从 GitHub 克隆源码后，将 `OG_EDITOR_WORKSPACE` 指向存放下列文件的工作区。如果源码已经放在工作区的 `02_修改工具` 下，程序会从上两级目录查找。

| 本地文件 | 程序用它做什么 |
| --- | --- |
| 奥0基准 EBOOT、角色绑定表、动作表、YUM 资源索引和读取脚本 | 校验镜像，查找角色、招式和素材。目录由 [paths.py](../ogeditor/paths.py) 中的 `psp_reference` 定位。 |
| `02_修改工具/Blender_MDL/当前版本/Blender_MDL编辑与替换工具_v1.1.0/io_scene_kgf_mdl` | 读取镜像、角色模型与贴图，转换替换用的模型。 |
| `02_修改工具/猪猪修改工坊` 和 `02_修改工具/PSP统一工具/Source/ENC` | 读写资源库，处理 ENC 压缩数据。 |
| `select_page_bases.dat` 和 `move_bank_layouts.dat` | 识别奥0的选人页和配招资源布局。可放在 `viewer.py` 旁边，也可沿用既有工作区里的存放位置。 |

实际需要的文件名都列在 [打包清单](../ogeditor.spec) 里。这些本地依赖需要另外准备。

## 启动修改器

在仓库根目录打开 PowerShell。第一行换成自己的工作区路径。

```powershell
$env:OG_EDITOR_WORKSPACE = 'D:\游戏编辑工作区'
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe viewer.py
```

也可以把 ISO 路径作为第一个参数传给 `viewer.py`，启动时直接打开这张镜像。

## 打包 EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm ogeditor.spec
```

生成的程序是 `dist/奥特曼游戏修改器.exe`。它包含奥0镜像校验所用的基准文件和运行索引，构建后保存在本地。

## 运行测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
node --test tests/event_list.test.mjs
```

Python 测试检查工程重开、镜像另存、配招分段、贴图色表和战斗参数。缺少对应游戏镜像时，相关用例会显示为跳过。前端测试检查切换 **当前帧** 和 **整段** 时显示哪些事件、选中了哪一行。
