# 运行、构建与测试

## 准备本地运行依赖

已核对的环境为 Windows x64、Python 3.13 和 Microsoft Edge WebView2。音频转换和奥3 IPU 影片预览另外使用 PATH 中的 FFmpeg。

独立克隆后，将环境变量 `OG_EDITOR_WORKSPACE` 指向已有的 KGF 工作区根目录。若本来就在工作区的 `02_修改工具/奥格资源编辑器融合版本` 下运行，则使用原有的相对目录布局。

| 工作区下的本地位置 | 作用 |
| --- | --- |
| `04_补丁与研究/KGF_v7_阶段1_EBOOT分析` | v7 镜像基准、角色绑定、动作映射、YUM 索引，以及打包清单指定的读取脚本和基准 EBOOT。 |
| `02_修改工具/Blender_MDL/当前版本/Blender_MDL编辑与替换工具_v1.1.0/io_scene_kgf_mdl` | MDL、POM、镜像及模型转换读取模块。 |
| `02_修改工具/猪猪修改工坊` 和 `02_修改工具/PSP统一工具/Source/ENC` | 资源库替换、ISO 文件访问和 ENC 处理模块。 |
| `02_修改工具/奥格资源编辑器融合版本` | 两份版本适配数据 `select_page_bases.dat` 和 `move_bank_layouts.dat`。也可放在克隆目录根部。 |

实际打包所需的逐文件清单见 [KGF-v7.spec](../KGF-v7.spec)。只有这个 Git 仓库和 Python 依赖时，还缺上表所列的本地文件。

## 从源码运行

以下 PowerShell 命令均在仓库根目录执行。将示例路径改为自己的工作区路径。

```powershell
$env:OG_EDITOR_WORKSPACE = 'D:\KGF2.7'
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe viewer.py
```

也可将镜像路径作为 `viewer.py` 的第一个参数传入。

## 打包 Windows EXE

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm KGF-v7.spec
```

产物位于 `dist/奥格资源编辑器融合版本.exe`。打包会将本地基准数据嵌入 EXE，请将构建产物保存在本地。

## 测试

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
node --test tests/event_list.test.mjs
```

Python 用例覆盖工程读写、镜像另存与读回、配招分段、贴图色表和原生参数。需要特定镜像的用例按各测试中的条件启用，请核对测试输出里的跳过数。前端事件列表测试另需 Node.js。
