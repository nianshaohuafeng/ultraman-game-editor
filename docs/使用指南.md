# 使用指南

## 存工程，还是存镜像？

- **保存工程** 会生成 `.kgfp`。下次点 **打开工程** 就能接着改。如果移动过原 ISO，打开工程时重新选中同一张镜像。
- **导出改动包** 会生成 `.kgfpatch`，适合把改动交给使用同一版本镜像的人。
- **另存新镜像** 会把当前修改写入另一张 ISO。奥0用 PPSSPP 打开，奥3用 PCSX2 打开。

## 奥0 · 改赛文 ↓＋○ 的第二段伤害

1. 选赛文，在 **必杀技配置** 中选 **↓＋○**，点 **同步预览**。原招起手是状态 160、ANM 201，后续发射在状态 161、ANM 202。
2. 在 **招式分段** 选第 2 段，点 **编辑本段帧事件**。这里从第二段的开头算帧。
3. 切到 **整段**，找到第 25 帧的攻击记录，修改 **基础伤害** 并应用。要回看命中时刻，可以在预览里停到第 25 帧，再切回 **当前帧**。
4. 存下工程，或点 **另存新镜像** 进游戏试招。若已把这招移植给其他角色，用 **招式分段** 找第二段，移植后的状态和 ANM 编号可能会变。

改跑速时，进 **角色属性** 选要改的生命分段，再调 **地面移动倍率**。步行、冲刺和跑动都用这个值。要让角色从满血到残血都用同一倍率，每个分段都要填。自然回复能量的速度在同一页的 **回气倍率**。

## 奥3 · 改蓄力时间、评级和伤害

| 想要的效果 | 改哪一项 |
| --- | --- |
| 超重击后更快蓄满 | 在 **必杀技配置 → 超重击后 · 必杀前蓄力** 调低 **常规蓄满帧数**。TAG 模式的特殊情况有单独一栏。这两项对全体角色生效。 |
| 某一招能更早发动 | 选中该招，调低 **释放所需蓄力值**。这个数是发动时需要攒够的点数，蓄力槽上限是 256。 |
| 调整菜单显示的 S～E 评级 | 在 **必杀技配置** 里选技能并调整评级。游戏会按已装备的必杀组合重算装备栏评级。 |
| 调整招式实际扣血 | 选中招式，在 **招式与判定** 里找到命中的攻击记录，修改它的伤害。多段攻击要逐段核对命中帧。 |
