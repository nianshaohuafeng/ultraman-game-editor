# 使用指南

## 镜像、工程和改动包

打开 ISO 后，先选角色、形态和动作。**应用到工程**会更新本次编辑。**保存工程**生成 `.kgfp`，可在之后重新打开。工程与来源镜像关联，重新打开时应使用相同基底。**导出改动包**生成 `.kgfpatch`。**另存新镜像**将改动写入新的 ISO，随后可在 PPSSPP 或 PCSX2 中测试。

## 奥0：修改多段必杀的后半段

以赛文的 **↓＋○** 为例。在 **必杀技配置** 中选中它，点 **同步预览**。起手是状态 160、ANM 201，接续是状态 161、ANM 202。

要改后半段，在 **招式分段** 中选第 2 段，点 **编辑本段帧事件**。这里的帧号从本段起点计算。比如要改第 25 帧的攻击参数，选中该事件，修改基础伤害后应用，再另存镜像。移植到别的角色后，目标状态和 ANM 编号可能重新分配，应以当前分段选择器为准。

**角色属性**按生命分段保存数值。调整步行、冲刺和跑动时编辑 **地面移动倍率**；调整能量自然回复时编辑 **回气倍率**。要让改动覆盖整条生命槽，需要设置所有目标分段。

## 奥3：分别调整蓄力与伤害

- **必杀技配置**中的**释放所需蓄力值**决定该招的蓄力门槛。超重击后的蓄满帧数另有入口。
- **动作与战斗**中的帧事件或批量伤害编辑用于调整命中时读取的攻击参数。修改前可用预览核对 ANM、触发帧和目标形态。
- 候选评级、装备组合与实际扣血有各自的计算路径。需要改变扣血时，应检查攻击事件及相关演出。
