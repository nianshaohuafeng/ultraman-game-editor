# 奥特曼游戏修改器

在 Windows 上编辑《奥特曼格斗进化0》（奥0）和《奥特曼格斗进化3》（奥3）。可以逐帧看招式在哪一帧命中，改那一击的伤害，也可以给角色换招、换模型和贴图。改好的内容先存成工程，想进游戏试招时再另存一张 ISO。

## 从哪里开始

打开 **奥特曼游戏修改器.exe**，点 **打开 ISO**，选好角色和形态。双击招式就能播放，拖动时间轴可以停在某一帧。找不到某个面板时，按 **Ctrl+K** 搜它的名字。

| 想改什么 | 去哪里 |
| --- | --- |
| 某一击的伤害 | 奥0在 **帧事件** 里选攻击记录，奥3在 **招式与判定** 里选。**当前帧** 只看这一帧生效的事件，**整段** 列出这段动作的全部事件。 |
| 给角色换招 | **配招** 可以从其他角色挑选动作。奥3要把一招加进游戏里的可装备列表，进 **必杀技配置 → 新增必杀技**。 |
| 模型或贴图 | 在 **外观与贴图** 中选资源，预览后点 **导入替换**。奥0还可以导入 OBJ 和 FBX 并绑定角色骨架。 |
| 移动、耗能或蓄力 | 奥0在 **角色属性** 里改地面移动倍率和技能耗能。奥3在 **必杀技配置** 里改超重击后的蓄力时间。 |

奥0还可以按角色和难度调电脑 AI，或给移植来的招式单独改伤害、换技能贴图。奥3的 **防御与辅助** 可以借用其他角色的技能。

想试试多段招式？可以从赛文的 **↓＋○** 入手，跟着例子改第二段第 25 帧的伤害。[使用指南](docs/使用指南.md)

## 主要文件

| 文件 | 负责什么 |
| --- | --- |
| [viewer.py](viewer.py) | 程序入口。打开桌面窗口，处理选镜像、切角色和保存工程等操作。 |
| [project_file.py](project_file.py) | 读写工程和改动包，重开时核对来源镜像。 |
| [iso_save.py](iso_save.py) | 将改动写进新的奥0镜像，处理资源大小变化后的文件位置。 |
| [formats.py](formats.py) | 读取奥0的骨骼动画（ANM）和帧事件（BOM），供预览和时间轴使用。 |
| [event_edits.py](event_edits.py) | 修改帧事件里的触发时间、伤害、音效和手型。 |
| [cross_move.py](cross_move.py) | 在两作之间移植动作，将姿势和命中位置对齐到目标角色。 |
| [cross_timing.py](cross_timing.py) | 动作变长或变短时，按原来的节奏换算事件帧号。 |
| [cross_texture.py](cross_texture.py) | 把奥3角色贴图转成奥0的 POM，同时换算纹理坐标。 |
| [fbx_textures.py](fbx_textures.py) | 导入 FBX 时找到材质使用的 PNG，分配给奥0模型的贴图槽。 |
| [move_sound.py](move_sound.py) | 查找角色音效和战吼，随招移植或从 WAV 导入。 |
| [move_eboot.py](move_eboot.py) | 把配招写进奥0的 EBOOT，重开镜像时识别已有配招。 |

奥0和奥3各自的角色与技能代码在 [ogeditor/psp](ogeditor/psp/) 和 [ogeditor/ps2](ogeditor/ps2/)。模型导入和跨游戏转换分别在 [models](ogeditor/models/) 和 [transfer](ogeditor/transfer/)。要改面板或 3D 预览，看 [web](web/)。

## 从源码运行

仓库包含修改器源码、界面和测试。运行源码还需要本地的镜像读取模块和奥0基准文件。依赖清单、启动命令和 EXE 打包步骤见 [构建与测试](docs/构建与测试.md)。
