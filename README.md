# 奥格资源编辑器 · 融合版

奥格资源编辑器是一款 Windows 桌面工具，可以在同一个窗口里编辑 PSP《奥特曼格斗进化0》KGF v7 和 PS2《奥特曼格斗进化3》的受支持镜像。选择角色、形态和招式后，可以播放动作、逐帧检查判定、修改资源，再将结果另存为新的 ISO。

## 可以用它做什么

| 工作内容 | 编辑器中的操作 |
| --- | --- |
| 查看招式 | 旋转 3D 模型、切换骨架和判定显示，在时间轴上定位攻击、音效和特效事件。 |
| 编辑角色与资源 | 修改角色属性，导出或替换模型、贴图与音频。奥0支持导入外部 OBJ、FBX 并绑定到目标骨架。 |
| 移植招式 | 在角色间配置动作和技能。奥0支持独立编辑移植后的分段动作、关键帧、伤害与技能贴图；跨游戏转换的范围随来源和目标而定。 |
| 调整战斗参数 | 奥0可编辑地面移动倍率、回气倍率、技能耗能和电脑 AI；奥3可编辑必杀蓄力、评级、防御与辅助技，以及攻击事件的伤害。 |
| 保存修改 | 保存为可继续编辑的工程，导出改动包，或另存一张试用镜像。 |

## 第一次使用

1. 在 Windows 上启动编辑器，点 **打开 ISO**，选择自己的游戏镜像。
2. 在左栏选择角色和形态，双击动作列表中的招式开始预览。
3. 在右侧工作区修改目标字段，点 **应用到工程**。
4. 点 **保存工程** 留下可继续编辑的版本。要在模拟器中测试，点 **另存新镜像**，打开新生成的 ISO。

奥0以 KGF v7 及工具已识别的派生镜像为基底。奥3支持已核对的日版 `SLPS_254.41` 布局。编辑器在打开时校验版本。
